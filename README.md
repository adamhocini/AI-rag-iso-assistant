# Assistant IA RAG ISO - MVP local

PoC pédagogique d'assistant IA RAG sécurisé permettant d'interroger une documentation ISO fictive.

## Objectif

Construire un assistant capable de répondre à des questions sur un corpus documentaire qualité fictif, avec :

- réponses sourcées ;
- extraits utilisés ;
- niveau de confiance ;
- limites de réponse ;
- journalisation minimale ;
- préparation d'éléments d'audit.

## Stack MVP

- Python
- Streamlit
- ChromaDB
- OpenAI API ou Azure OpenAI
- Documents Markdown ou PDF fictifs
- Logs locaux
