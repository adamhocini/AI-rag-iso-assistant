# Procédure de gestion des risques

## 1. Objet

Cette procédure décrit une méthode simple d'identification, d'évaluation, de traitement et de suivi des risques qualité.

## 2. Identification des risques

Les risques peuvent être identifiés à partir :

- des audits internes ;
- des non-conformités ;
- des réclamations ;
- des changements d'organisation ;
- des fournisseurs critiques ;
- des retours des pilotes de processus.

## 3. Évaluation

Chaque risque est évalué selon deux critères :

- probabilité ;
- impact.

Un niveau de criticité peut être calculé de manière simple :

criticité = probabilité x impact.

## 4. Traitement des risques

Les options de traitement sont :

- accepter le risque ;
- réduire le risque ;
- transférer le risque ;
- éviter le risque ;
- surveiller le risque.

## 5. Suivi

Les risques significatifs doivent être suivis dans un plan d'action ou un registre spécifique.
