# Compte rendu fictif d'audit interne achats

## 1. Informations générales

- Date de l'audit : 2025-03-12
- Processus audité : Achats
- Auditeur : Auditeur Interne
- Personnes rencontrées : Responsable Achats, Assistant Achats
- Référentiel interne utilisé : fiche processus achats FP-ACH-001 version 1.0

## 2. Documents consultés

Les documents consultés pendant l'audit sont :

- FP-ACH-001 : fiche processus achats ;
- PROC-NC-001 : procédure de gestion des non-conformités ;
- PROC-AUD-001 : procédure d'audit interne ;
- REG-AC-001 : registre des actions correctives ;
- trois commandes fournisseurs ;
- deux évaluations fournisseurs ;
- un tableau de suivi des demandes d'achat.

## 3. Constats positifs

Le processus achats est globalement décrit et les responsabilités sont connues par les personnes rencontrées.

Les commandes vérifiées disposent d'une validation hiérarchique.

Les écarts fournisseurs sont bien orientés vers la procédure de gestion des non-conformités.

## 4. Non-conformité NC-2025-001

Deux fournisseurs actifs ne disposent pas d'une évaluation fournisseur récente.

Cette situation ne respecte pas les règles définies dans la fiche processus achats.

Une action corrective doit être ouverte pour mettre à jour les évaluations fournisseurs.

## 5. Point sensible PS-2025-001

Le délai de traitement des demandes d'achat est mentionné comme indicateur, mais son suivi mensuel n'est pas systématique.

Ce point doit faire l'objet d'un suivi par le Responsable Achats.

## 6. Conclusion

L'audit interne du processus achats a bien été réalisé.

Les preuves disponibles sont :

- compte rendu d'audit CR-AUD-2025-001 ;
- liste des documents consultés ;
- constats d'audit ;
- non-conformité NC-2025-001 ;
- point sensible PS-2025-001 ;
- actions correctives associées dans REG-AC-001.

## 7. Alerte documentaire

Le compte rendu mentionne la fiche processus achats FP-ACH-001 en version 1.0, alors que la version applicable actuelle est la version 1.1.

Cette différence doit être vérifiée par le Responsable Qualité.
