# Procédure de gestion des non-conformités

## 1. Objet

Cette procédure décrit la méthode de détection, d'enregistrement, d'analyse, de traitement et de clôture des non-conformités.

## 2. Définition

Une non-conformité est un écart entre une exigence attendue et une situation constatée.

Elle peut provenir :

- d'un audit interne ;
- d'une réclamation client ;
- d'un contrôle fournisseur ;
- d'une erreur documentaire ;
- d'un dysfonctionnement opérationnel.

## 3. Enregistrement

Toute non-conformité doit être enregistrée avec les informations suivantes :

- identifiant unique ;
- date de détection ;
- processus concerné ;
- description de l'écart ;
- niveau de criticité ;
- responsable du traitement ;
- action immédiate éventuelle ;
- décision de traitement.

## 4. Analyse des causes

Le responsable du traitement analyse les causes de la non-conformité.

L'analyse peut s'appuyer sur une méthode simple comme les 5 pourquoi ou le diagramme causes-effets.

## 5. Traitement

Les traitements possibles sont :

- correction immédiate ;
- action corrective ;
- acceptation justifiée ;
- surveillance renforcée ;
- escalade vers la direction.

## 6. Action corrective

Une action corrective doit être créée lorsque la non-conformité révèle une cause récurrente ou un risque significatif.

L'action corrective est suivie dans le registre REG-AC-001.

## 7. Clôture

Une non-conformité peut être clôturée lorsque :

- la correction a été réalisée ;
- la cause a été analysée ;
- l'action corrective éventuelle est définie ;
- les preuves sont disponibles ;
- le Responsable Qualité a validé la clôture.

## 8. Preuves attendues

Les preuves attendues sont :

- fiche de non-conformité ;
- analyse des causes ;
- preuve de correction ;
- action corrective associée ;
- validation de clôture.
