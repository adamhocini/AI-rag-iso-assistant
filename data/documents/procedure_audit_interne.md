# Procédure d'audit interne

## 1. Objet

Cette procédure définit les règles de planification, préparation, réalisation, restitution et suivi des audits internes.

## 2. Planification

Un programme d'audit interne est établi au moins une fois par an.

Le programme doit couvrir les processus importants du système qualité, notamment :

- qualité ;
- achats ;
- gestion documentaire ;
- non-conformités ;
- risques.

## 3. Préparation de l'audit

Avant l'audit, l'auditeur prépare une checklist adaptée au processus audité.

La checklist peut contenir :

- les exigences documentaires ;
- les documents applicables ;
- les preuves attendues ;
- les personnes à interroger ;
- les points de contrôle.

## 4. Réalisation

L'auditeur collecte des preuves objectives.

Les preuves peuvent être :

- documents validés ;
- enregistrements ;
- entretiens ;
- observations terrain ;
- extractions de registres ;
- comptes rendus.

## 5. Restitution

À la fin de l'audit, l'auditeur présente les constats.

Les constats peuvent être classés comme :

- conformité ;
- point sensible ;
- non-conformité mineure ;
- non-conformité majeure ;
- opportunité d'amélioration.

## 6. Compte rendu d'audit

Un compte rendu d'audit doit contenir :

- date de l'audit ;
- périmètre ;
- auditeur ;
- personnes rencontrées ;
- documents consultés ;
- constats ;
- éventuelles non-conformités ;
- actions à suivre.

## 7. Suivi

Les non-conformités détectées lors d'un audit doivent être traitées selon la procédure PROC-NC-001.

Les actions correctives associées doivent être enregistrées dans REG-AC-001.
