# Manuel qualité fictif

## 1. Objet

Ce manuel qualité décrit l'organisation générale du système de management de la qualité de l'entreprise fictive QualiDemo.

Il présente les processus principaux, les responsabilités, les règles documentaires et les principes d'amélioration continue.

## 2. Domaine d'application

Le système qualité couvre les activités suivantes :

- gestion documentaire ;
- achats ;
- audits internes ;
- gestion des non-conformités ;
- gestion des risques ;
- actions correctives ;
- amélioration continue.

## 3. Responsabilités principales

La Direction Générale définit la politique qualité et valide les objectifs annuels.

Le Responsable Qualité maintient le système documentaire, planifie les audits internes et suit les actions correctives.

Les pilotes de processus sont responsables de l'application des procédures dans leur périmètre.

## 4. Documents associés

Les documents principaux du système qualité sont :

- PROC-DOC-001 : Procédure de gestion documentaire ;
- PROC-NC-001 : Procédure de gestion des non-conformités ;
- PROC-AUD-001 : Procédure d'audit interne ;
- PROC-RISK-001 : Procédure de gestion des risques ;
- FP-ACH-001 : Fiche processus achats ;
- REG-AC-001 : Registre des actions correctives.

## 5. Maîtrise documentaire

Chaque document qualité doit comporter une référence, une version, un statut, une date de validation, un propriétaire et un processus concerné.

Un document applicable doit avoir le statut "Validé".

Les documents avec le statut "Brouillon", "Obsolète" ou "En révision" ne doivent pas être utilisés comme référence principale sans validation humaine.

## 6. Amélioration continue

Les non-conformités, audits internes, risques et réclamations peuvent déclencher des actions correctives.

Les actions correctives sont suivies dans un registre dédié.

Chaque action doit avoir un responsable, une échéance, un statut et une preuve de clôture lorsque l'action est terminée.
