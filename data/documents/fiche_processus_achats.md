# Fiche processus achats

## 1. Finalité du processus

Le processus achats vise à sélectionner, commander et suivre les fournisseurs afin de garantir la conformité des produits et services achetés.

## 2. Entrées du processus

Les principales entrées sont :

- besoin interne validé ;
- cahier des charges ;
- demande d'achat ;
- liste des fournisseurs référencés ;
- exigences qualité applicables.

## 3. Activités principales

Les activités du processus achats sont :

1. analyser le besoin ;
2. consulter les fournisseurs ;
3. comparer les offres ;
4. sélectionner le fournisseur ;
5. passer la commande ;
6. réceptionner le produit ou service ;
7. traiter les écarts éventuels ;
8. évaluer périodiquement les fournisseurs.

## 4. Sorties du processus

Les sorties attendues sont :

- commande validée ;
- produit ou service réceptionné ;
- preuve de conformité ;
- évaluation fournisseur ;
- non-conformité fournisseur si nécessaire.

## 5. Indicateurs

Les indicateurs suivis sont :

- taux de commandes conformes ;
- délai moyen de traitement des demandes d'achat ;
- nombre de non-conformités fournisseurs ;
- taux de fournisseurs évalués.

## 6. Risques du processus achats

Les risques principaux sont :

- fournisseur non évalué ;
- retard de livraison ;
- produit non conforme ;
- absence de preuve de réception ;
- commande passée sans validation.

## 7. Documents associés

Les documents associés sont :

- PROC-NC-001 : gestion des non-conformités ;
- PROC-RISK-001 : gestion des risques ;
- REG-AC-001 : registre des actions correctives ;
- CR-AUD-2025-001 : compte rendu d'audit interne achats.

## 8. Preuves attendues lors d'un audit

Les preuves attendues pour auditer le processus achats sont :

- demande d'achat validée ;
- commande ;
- preuve de réception ;
- évaluation fournisseur ;
- traitement des écarts ;
- actions correctives en cas de non-conformité.
