# Procédure de gestion documentaire

## 1. Objet

Cette procédure définit les règles de création, validation, diffusion, révision et archivage des documents qualité.

## 2. Types de documents concernés

Les documents concernés sont :

- manuel qualité ;
- procédures ;
- fiches processus ;
- formulaires ;
- registres ;
- comptes rendus d'audit ;
- plans d'actions.

## 3. Règles de création

Tout document qualité doit contenir les informations suivantes :

- titre ;
- référence unique ;
- version ;
- statut ;
- date de validation ;
- propriétaire ;
- processus concerné ;
- type de document.

## 4. Cycle de vie documentaire

Un document peut avoir les statuts suivants :

- Brouillon ;
- En révision ;
- Validé ;
- Obsolète.

Seuls les documents au statut "Validé" sont applicables.

Un document en révision peut être consulté, mais il ne doit pas être utilisé comme preuve principale lors d'un audit sans confirmation du Responsable Qualité.

## 5. Validation

La validation d'un document est réalisée par le propriétaire du document et par le Responsable Qualité.

La date de validation doit être renseignée dans les métadonnées du document.

## 6. Révision périodique

Chaque document qualité doit être revu au minimum tous les trois ans.

Si la date de validation est trop ancienne, le document doit être analysé avant utilisation.

## 7. Archivage

Lorsqu'un document est remplacé, son ancienne version prend le statut "Obsolète".

Les documents obsolètes sont conservés à titre de preuve historique, mais ne doivent pas être utilisés comme référence applicable.

## 8. Preuves attendues

Les preuves de bonne gestion documentaire peuvent être :

- liste des documents applicables ;
- historique des versions ;
- validation du Responsable Qualité ;
- registre de diffusion ;
- compte rendu de revue documentaire.
