# Registre fictif des actions correctives

## 1. Objet

Ce registre permet de suivre les actions correctives issues des audits internes, non-conformités, réclamations et analyses de risques.

## 2. Actions enregistrées

### AC-2025-001

- Origine : audit interne achats
- Référence de l'écart : NC-2025-001
- Description : absence de preuve d'évaluation fournisseur pour deux fournisseurs actifs.
- Responsable : Responsable Achats
- Échéance : 2025-04-30
- Statut : Clôturée
- Preuve de clôture : grille d'évaluation fournisseur mise à jour le 2025-04-25.

### AC-2025-002

- Origine : audit interne achats
- Référence de l'écart : NC-2025-002
- Description : délai de traitement des demandes d'achat non suivi mensuellement.
- Responsable : Responsable Achats
- Échéance : 2025-05-31
- Statut : En cours
- Preuve de clôture : non disponible à ce jour.

### AC-2025-003

- Origine : revue documentaire
- Référence de l'écart : NC-2025-003
- Description : procédure de gestion des risques en révision depuis plus de douze mois.
- Responsable : Responsable Qualité
- Échéance : 2025-06-15
- Statut : En retard
- Preuve de clôture : non disponible.

## 3. Règles de suivi

Chaque action corrective doit être suivie jusqu'à clôture.

Une action en retard doit être signalée au Responsable Qualité.

Une action clôturée doit disposer d'une preuve vérifiable.
